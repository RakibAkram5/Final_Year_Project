# Teacher guide

You see only the classes where you are the assigned teacher.

| Task | Where |
|---|---|
| Mark attendance | Dashboard → **Attendance** → class → mark present / absent / late / leave → save. Saving again the same day corrects the record (no duplicates). Future dates are not allowed. |
| Share notes, slides, worksheets | Dashboard → **Resources** → class → **Share material** → choose a file (PDF, Word, PowerPoint, Excel, image, text; ≤ 4 MB), title, optional description/link. Students of that class and their parents can preview and download it. Use **Replace** or **Delete** on a file to update it. |
| Assignments | Dashboard → **Assignments** → **New assignment** → class, title, instructions, due date/time, max marks, whether students may replace their upload. Open the assignment to attach instruction files, see submissions (late ones are marked), open a student's files and **Grade** (marks cannot exceed the maximum). |
| Tests and marks | Quizzes → create a test (or generate from OCR), enter marks; marks above the total are rejected. |
| Online tests | When creating a test, switch on **Students attempt this test online** (section *Online attempt*) and optionally set a time limit and a deadline. Students then attempt it in their portal. Open the test → **Submissions & grading**: multiple-choice answers are already scored; enter marks for each written answer (0 … question marks), add a note and **Save marks & publish result**. The result becomes a normal test mark once every question is scored. Tests you leave as paper behave exactly as before (print, AI grader, manual marks). |
| Student questions | Class → **Student queries** → answer. |
| Reports | Dashboard → **Reports** → class → attendance or results as PDF or Excel. |
| Timetable | **My Timetable**. |
| Academy location | **Academy Location** → map and directions. |

Tip: on small phones, card actions you do not see are in the **⋮** menu.
