# Student guide

| Task | Where |
|---|---|
| Classes and materials | **My Classroom Hub** → a class → **Resources**: preview PDFs (scroll, pinch or double-tap to zoom) and images, or **Download** any file. |
| Assignments | **Assignments** → open one → read the instructions and files → **Start submission** → **Upload** your work (PDF, Word or image, ≤ 4 MB). Before the deadline you can replace it if the teacher allowed it. After grading you see your marks and feedback. |
| Timetable | **My Timetable**. |
| Attendance | **My Attendance** — daily view and percentage. |
| Results | **Results** — test marks, grades, progress chart, PDF report. |
| Fees | **Fees** → challan → **PAY NOW** shows the academy's bank details/IBAN (tap to select and copy) and QR. Upload a photo of your receipt; the fee is marked paid only after the academy verifies it. |
| Documents | **My Documents** — admission papers and certificates the academy uploaded for you. |
| Academy location | **Academy Location** → map, **Directions**. |
| Notes summariser | **AI Notes** — automatic extractive summary of pasted/scanned text. |
