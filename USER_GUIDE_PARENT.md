# Parent guide

Your children are linked to your account **by the academy admin**. If a child
is missing, ask the academy to link them, then pull down on the dashboard to
refresh (the app also re-checks every few minutes). If the app cannot reach
the server you will see a message with **Retry** — this does not mean your
children were unlinked.

| Task | Where |
|---|---|
| See all children | Dashboard → **My Children** (every linked child is listed; tap one to open it) |
| Attendance | child → **Attendance History** |
| Results and progress | child → test report and progress chart |
| Assignments | child → **Assignments** → status (Pending / Submitted / Graded / Missed), marks, teacher feedback and the submitted files |
| Timetable | Dashboard → child card **⋮** → **View Timetable** |
| Fees and payment | **Fee Challans** → challan → **PAY NOW** → bank, account number, IBAN, instructions, QR. Upload the receipt; the academy verifies it before marking the fee paid. Download the voucher as PDF. |
| Documents | child → **Documents** (admission papers, certificates) |
| Academy contact and location | **Academy Support** → contact details, map and **Directions** |
| Notices | **Announcements** and the bell icon |

You can only see your own linked children; the app never shows other students' data.
